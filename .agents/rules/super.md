# Professional Standards & "No Guessing" Rule (General Application)

When working on this project, you MUST adhere to the following strict professional standards in ALL areas (not just UI/Assets):

1. **NO "Hebd" (Guessing/Hallucinating) in Anything:** 
   - Whether it's complex logic, API integrations, backend structure, or UI, **NEVER** invent solutions if you don't know the exact answer or lack context.
   - If you don't know something, admit it immediately.

2. **Confront the User When Stuck:** 
   - If you hit a roadblock, lack a specific key, do not understand a requirement, or cannot execute a task to a 100% professional enterprise standard, **STOP**.
   - Confront the user clearly: "I cannot do X professionally without Y. Please provide Y or advise on how to proceed."

3. **Zero Compromise on Quality:**
   - Every single line of code must be production-ready.
   - Do not use temporary patches, fake data, mock statistics, or generic placeholders in any part of the application.
