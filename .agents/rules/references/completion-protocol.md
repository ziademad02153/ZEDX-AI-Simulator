# Completion Protocol

## Allowed Final Statuses
- COMPLETE — every required criterion met and verified with evidence
- PARTIALLY_COMPLETE — some work remains; list exactly what
- BLOCKED — external or missing information prevents progress; state the exact blocker and what is required
- FAILED — verification or implementation failed; state the failure and supporting evidence

## Forbidden Phrases Without Evidence
- “Done.”
- “Fixed.”
- “All tests pass.”
- “The feature is complete.”
- “Everything works.”

## Preferred Final Response Shape (engineering tasks)
Summary
- what changed (files / behavior)

Verification
- what was checked
- concrete results

Remaining
- incomplete, blocked, or failed items (if any)

Keep the response proportional to the work. Thorough internal process does not require long performative text.
